# Lifeloom

Personal life-planning app. Frontend and backend are separate.

Open one area file for the task. Leave the other unread.

| Area | Purpose | Map |
| --- | --- | --- |
| client | Expo React Native app for Android and iOS. Built against the server. | `.cursor/maps/client.md` |
| server | NestJS REST backend with MongoDB, private media, and durable delivery. | `.cursor/maps/server.md` |
